# Roube um Ovo: Cyber Lógico — V2

Jogo educativo local em React, Tailwind CSS e Canvas 2.5D. Cinco zonas desbloqueáveis, sete raridades, criaturas equipáveis e incubação de 10 a 60 segundos. Controles WASD/setas, E/espaço e direcional no celular. Progresso salvo no navegador (novo save V2).

## Publicar no Vercel
Importe este repositório na branch main, com Framework Preset Other e diretório raiz. Não precisa de npm, build ou variáveis de ambiente. Clique em Deploy.

## Evolução
Desbloqueie zonas com moedas, entregas, acertos e incubações. Guardas mais velozes e numerosos nas zonas avançadas. Ovos reaparecem por sorteio; o Secreto só aparece na última zona, com 1% de chance nos setores elegíveis.
